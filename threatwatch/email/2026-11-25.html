2. Critical Vulnerability Intelligence

CVE-2025-34035 - Engeniustech Esr600 Firmware OS command injection (CVSS 10). An OS command injection vulnerability exists in EnGenius EnShare Cloud Service version 1.4.11 and earlier. The usbinteract.cgi script fails to properly sanitize user input passed to the path parameter, allowing unauthenticated remote attackers to inject arbitrary shell commands. The injected commands are executed with root privileges, leading to full system compromise. Affected releases (NVD): esr300 firmware = 1.1.0.28; esr300 firmware = 1.3.1.42; esr300 firmware = 1.4.0; +22 more. Fixed package release: none identified in tracked sources. Attack path: network-accessible; no authentication required; no user interaction required.

CVE-2026-135736 - Ffmpeg out-of-bounds write (CVSS 9.2). FFmpeg 4.4 before 9.1 contains a heap out-of-bounds read and write vulnerability in libavfilter/vf_deband.c that allows attackers to corrupt heap memory by sending a runtime coupling command. Attackers can send a 'deband coupling 1' command via sendcmd or an unauthenticated zmq filter, making chroma planes be processed at luma dimensions to crash the process or potentially execute code. Affected releases (NVD): ffmpeg >= 4.4, < 9.1. Fixed version (first unaffected release per NVD ranges): ffmpeg 9.1. Attack path: network-accessible; no authentication required; no user interaction required.
